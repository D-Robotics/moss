## Moss vs Mainstream Agents 深度对比分析

撰写了 `docs/MOSS_VS_MAINSTREAM_AGENTS.md`，基于真实源码（agent loop / context / tools / safety / memory / skills / teaching / mesh）与 Claude Code、Cursor、Aider、OpenAI Agents SDK、LangChain、AutoGen/CrewAI 做了 11 个维度的对比。

### 6 个 Moss 独特能力
1. **闭环自进化**：Teaching → Candidate → Scorer → Distiller → Promoter，主流 Agent 完全没有
2. **机器人原生**：/connect board、hybrid execution、GPIO/ROS2、DeviceFamily/VendorPlugin 契约
3. **宿主中立架构**：Host Adapter 契约，一套运行时嵌入任何产品
4. **零配置零 Key**：内置网关，一条 `moss` 命令启动
5. **深度安全**：6 层审批链 + Tool Loop Guard + Idempotent Replay + Steering Engine + Completion Gate
6. **自适应上下文**：ContextBudgetPlanner 渐进式压缩、BM25+Semantic RRF 混合搜索、Overflow Recovery 三级恢复

### 5 个当前缺失
