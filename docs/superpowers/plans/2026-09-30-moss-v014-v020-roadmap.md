## 关键技术决策(切片依赖这些,先拍板)

| #   | 决策         | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | 外部榜单     | 主榜 **SWE-bench Verified 固定 100 实例子集**(实例清单锁定入库 `bench/boards/swebench-instances.json`,按 repo 分层抽样、种子固定);副榜 Terminal-Bench 40 任务(0.16 引入,共用 Docker adapter 层)。adapter 复用现有 bench 跑法(spawn `dist/cli.js -p --output-format stream-json`)。**诚实口径**:模型钉死 DeepSeek,与前沿模型的绝对分差不可消除;"比肩主流"可证伪口径=同模型下 harness 版本间 delta(≥噪声带)+ 与公开 DeepSeek 系参照的差距量化表 |
| D2  | MCP 客户端   | stdio + streamable HTTP 双传输(不做 legacy SSE);放 `src/core/mcp/`(ESLint 新 boundary 端口);配置 `.moss/mcp.json` + `~/.moss/mcp.json`,凭据只走 env 展开;**懒加载必做**(CC MCPSearch 模式:系统提示只注入每 server 一行索引 + `mcp__search` 元工具,schema 按需拉取);工具名 `mcp__<server>__<tool>`,sideEffect 缺省 mutating 走审批                                                                                                             |

| D4  | hooks 事件   | 优先级 Stop > SubagentStop > PreCompact/PostCompact > SessionEnd > Notification。前四个进 0.15(Stop 是 CI 门与通知地基,成本最低);后两个进 0.16                                                                                                                                                                                                                                                                                                |
| D5  | TUI 框架     | ink + React,严格圈禁 `src/cli/tui/`(动态 import,headless/SDK 路径永不加载;boundary 规则禁 tui 外泄)。拒绝 blessed(无维护);拒绝自研 ANSI 层(Windows raw-mode/resize/IME 是坟场)。回退链:无 TTY 或 `--no-tty` → 现有 readline REPL 永久保留。**翻案叙事**:Esc 中断、运行中 steering、多行粘贴防炸、transcript 滚动回放——四者在 readline 下结构性做不彻底,非打磨问题                                                                             |
| D6  | 效率增量来源 | /goal 达标驱动(SWE +2~5pt)> worktree 并行子代理(内部 hard +3~6pt,SWE +0~2pt)> 网络出网策略(SWE ≈0,是 Terminal-Bench 联网任务前置)。版本 delta 目标:0.15 SWE ≥+3pt;0.16 SWE 不回退(±0)                                                                                                                                                                                                                                                         |
| D7  | 死命令止血   | 提前到 0.14(不等 TUI):幽灵子命令改非零退出+明确报错;死命令下架或标注未实现;删 input-queue.ts 死模块。真 handler 随 TUI 落地:/resume 回放 0.17,/steer /queue 0.18                                                                                                                                                                                                                                                                              |
