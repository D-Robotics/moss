# Moss v0.23 规划 · 能力层（2026-10-02 立项）

v0.22 已发布（精简发布：单一归宿 + 人眼视图 + 免询问）。v0.23 主题：**能力层的可用性**——让 MCP、
设备闭环、skills 三条能力线从"手写配置才知道存在"变成"一条命令进入"。

## 总目标

新用户从装好 moss 到第一次用上 MCP 工具/真机部署/自定义 skill，全程无需手编辑 JSON。
机器人闭环（governing P0）保持唯一完成机制（Task OS verdict），本版不动引擎语义。

## 量化验收（基线 → 目标）

| 指标            | v0.22           | v0.23 目标                                                                          |
| --------------- | --------------- | ----------------------------------------------------------------------------------- |
| 进入 MCP 的路径 | 手写 mcp.json   | `moss mcp add <name> <command>`（含 schema 校验 + add/list/remove/test 四命令）     |
| MCP 掉线恢复    | 重启 CLI        | 下次调用懒重连（1 次重试）+ `/mcp` 状态刷新                                         |
| 设备接入        | 单设备纯 env    | `.moss/devices.json` 持久注册（env-var 凭据引用）+ `moss device test` 连通/健康探测 |
| Skill 创建      | 手写 SKILL.md   | `moss skill create <name>` 脚手架 + skill 工具 args 传参 + 会话级 body 缓存         |
| Skill 基准      | 无              | 1 个 domain:skills bench 任务（创建+调用回归）                                      |
| 死代码          | /learn 幽灵引用 | 清除（skill-learning 注释、onboarding 计数、args 保留名）                           |

## 批次（每批独立 verify + CI 绿后合 main）

- **W1 · MCP 生命周期（最大杠杆）**
  - `moss mcp add|list|remove|test`，写用户/项目两级 mcp.json（与现有加载器同 schema）
  - add 时 schema 校验（command/args/env、URL 合法性），test 走一次真实 initialize+tools/list
  - registry 懒重连：closed 状态下下一次工具调用重试连接一次；`/mcp` 显示 lastError 与 retry 状态
  - 验收：四命令真实运行取证；掉线-重连单测（in-process server 关-开）；mcp bench 任务全绿
- **W2 · 设备注册与健康**
  - `.moss/devices.json`：多目标注册，凭据仍只经 env 引用（`password_env` 字段名，不落值）
  - `moss device test [name]`：连通 + 一个只读探测（device_info）+ 失败给下一步
  - `MOSS_DEVICE_HOST` 无设置时的首启引导改为指向 `moss device add`
  - 验收：in-process SSH 设备全链测试；凭据永不落盘断言（快照锁定 devices.json 形状）
- **W3 · Skills 可用性**
  - `moss skill create <name>`：生成 `.moss/skills/<name>/SKILL.md` 模板（frontmatter 提示 args）
  - skill 工具接受 `{name, args}`；SKILL.md 支持 `$ARGUMENTS` 注入（对齐 custom commands 语法）
  - 会话级 body 缓存（mtime 失效）；清除 skill-learning 死引用
  - 验收：创建→调用→args 注入真跑；bench 新增 domain:skills 任务；缓存命中断言
- **W4 · 收尾与发布**
  - `/skills` 浏览命令（REPL+TUI 同目录投影）；文档/帮助面更新（moss device/mcp/skill 进 brief help）
  - 全量 verify + examples + PTY dogfood（MCP add/test、device test、skill create 三路径）
  - 版本 0.23.0，发布口径更新，tag 按证据门

## Non-goals

不引入 memory/mesh/web-ui/plugin-market（维持冻结）；不改 Task OS 引擎与 verdict 语义；
不做多设备并发调度（fleet 执行编排是后续版）；MCP 不做 OAuth 流（stdio+env 够当前用户）。

## 决策点（默认按推荐执行，用户可推翻）

1. 凭据引用形态：`password_env: MOSS_DEVICE_PASSWORD`（推荐，值永不入文件）vs 明文入库
2. skill args 语法：`$ARGUMENTS` 占位（推荐，与 custom commands 一致）
3. `moss mcp test` 是否自动写 debug 日志（推荐：仅 stderr 摘要）
