
  moss  — standalone agent for robotics & edge devices

  Quick start
    $ moss                       # interactive TUI; built-in model works without login
    $ moss setup                 # optional: use your own provider, model, and API key
    $ moss --provider deepseek -m deepseek-v4-flash  # switch provider + model for this run
    $ moss resume --last         # continue the latest saved session
    $ moss --session work        # continue or create a named session
    $ moss "check disk usage"    # one-shot mode
    $ echo "list files" | moss   # piped stdin

  Setup & auth
    setup                 configure your own provider/model/API key
    auth login            optional: link a D-Robotics developer community account
    auth status           show community login and provider/model/key status
    auth logout           remove stored community login and API key config
    doctor                inspect config, auth, workspace, runtime, and update state
    update                run npm global update for Moss
    migrate               upgrade legacy dmoss dirs/sessions to moss (one-time)
    resume [--last]       resume a saved JSONL session
    fork [--last]         copy a saved session into a new branch
    mcp list             show configured MCP servers
    mcp add <name> <cmd> [args...] register an MCP server (no JSON editing)
    mcp remove <name>    remove a configured MCP server
    config               show resolved config values and sources
    config show          same as config; safe for scripts
    config show --json   emit redacted resolved config JSON
    config validate      check config files and audit warnings
    config validate --strict fail when audit warnings are present
    config init          create a user or project config file
    config set model <m>  update stored model
    config set baseUrl <u> update stored OpenAI-compatible base URL
    config set profile <p> cautious | balanced | autonomous
    config set provider <p> deepseek | qwen | openai | anthropic | openai-compatible
    config set imageInput <bool> send image_url parts to vision-capable providers
    config set trustedTools <csv> auto-approve tool names/globs after safety checks
    config set deniedTools <csv> always block tool names/globs
    config set promptCacheDebug <bool> enable prompt-prefix cache diagnostics
    config set guardrails.input.redactPatterns <csv> redact matching user text
    config set guardrails.output.blockPatterns <csv> block matching responses
    config set mcp.enabled <bool> enable MCP servers from config
    config set mcp.configPath <path> set MCP server config path
    config set agent.maxTurns <n> set per-request agent turn budget
    config set agent.contextTokens <n> set context budget used by pruning/compaction
    config unset <key>   remove a stored user/project override

  Interactive commands
    Work
      /status                  view model, workspace, device, and tool state
      /model                   choose or switch the active model for this session
      /goal                    show goal status, or pause / resume / complete / clear it
      /goal <objective>        set a goal and keep working toward it until you mark it done
      /compact                 compress older conversation history into a summary
      /compact [instructions]  compact and focus the summary on the given instructions
      /context                 show current context-window usage
      /connect <ip>            connect an RDK board and enter board mode (verifies SSH; flags: --user --port --key --password --no-verify --hybrid)
      /disconnect              leave board mode and restore local tools (Ctrl+D on an empty prompt also works)
      /review                  review the working-tree diff for bugs, security, and simplification
      /review <PR#>            review a GitHub pull request via `gh pr diff`
    Inspect
      /sessions                list saved conversations (use /resume to switch into one)
      /resume [key|--last]     switch this session to a saved conversation (no arg opens a picker)
      /mcp                     show configured MCP servers, connection status, and tool counts
      /doctor                  health-check model, egress, board, MCP, and config in this session
      /cost                    show recorded token usage and estimated cost
      /diff                    show git working-tree changes
      /rewind [seq]            undo file edits from a checkpoint
      /memory                  show project memory (AGENTS.md) and learned memories
    Configure
      /auth login              optional: link a D-Robotics developer community account
      /auth login --manual     optional browserless community login by pasting the redirect URL or token
      /logout                  log out of the D-Robotics developer community
      /quickstart              configure model, workspace, board, and first tasks
      /permissions             show safety, approvals, and how to grant full access
    Control
      /stop                    stop the active run
      /clear                   start a new conversation — clears the context window (aliases: /new, /reset)
      /init                    create an AGENTS.md project memory file
      /help                    show this command reference
      /quit                    exit Moss

  Flags
    --debug              verbose logging (level=debug)
    --quiet              only warnings & errors (level=warn)
    --log-level=<lv>   debug | info | warn | error
    --json               emit logs as JSON lines (log aggregators)
    -m, --model <m>     override model for this run
    -C, --cd <dir>      use a different workspace
    -c, --config k=v    override profile/model/provider/baseUrl/workspace/policy
    --config-file <p>   read/write an explicit config JSON file
    --provider <p>      deepseek | qwen | openai | anthropic | openai-compatible
    --base-url <url>    override provider base URL
    --session <key>     continue or create a named session key
    --last               with resume/fork, use latest session
    --ask-for-approval <p> never | prompt | on-request | read-only | workspace-write | full-access
    --read-only          block mutating tools
    --workspace-write    allow workspace writes/exec with approval (default)
    --full-access        allow device/external tools with approval
    --no-color           disable ANSI colors
    --help, -h           show this help
    --version, -v        show version

  Environment
    Variables use the MOSS_ prefix; the legacy MOSS_ names still work for now.
    Model settings (provider/model/baseUrl/apiKey) are never read from env vars —
    use moss setup / moss config set. Leftover DEEPSEEK_API_KEY etc. are ignored.
    MOSS_IMAGE_INPUT       =false to disable image input (on by default for all providers)
    MOSS_PROFILE           cautious | balanced | autonomous config profile
    MOSS_CONFIG_FILE       explicit config JSON path (overrides config dir)
    MOSS_WORKSPACE         working directory (default: cwd)
    MOSS_EXEC_BACKEND      local (default) or docker
    MOSS_BROWSER_EXECUTABLE Chrome/Chromium executable for browser tools
    MOSS_SAFETY_MODE       read-only | workspace-write | full-access
    MOSS_CLI_AUTO_APPROVE  =1 → approve allowed mutating tools without prompting
    MOSS_DOCKER_IMAGE      docker image (default: node:20-slim)
    MOSS_DEVICE_HOST       device IP/hostname (enables SSH tools)
    MOSS_DEVICE_USER       device SSH user (default: root)
    MOSS_DEVICE_PASSWORD   device SSH password
    MOSS_DEVICE_PORT       device SSH port (default: 22)
    MOSS_DEVICE_KEY        path to SSH private key
    MOSS_DEVICE_NO_VERIFY  =1 → skip the startup SSH reachability probe
    MOSS_DEVICE_HYBRID     =1 → keep local tools at startup instead of board mode
    MOSS_MESH_ENABLED      =true → start the agent mesh (MOSS_MESH_PORT/_PEERS/_SHARED_SECRET)
    MOSS_MCP_ENABLED       =true/false → override MCP enablement from config
    MOSS_MCP_CONFIG        path to MCP servers JSON (overrides config dir)
    MOSS_LOG_LEVEL         overrides default log level
    MOSS_LOG_JSON          =1 → JSON log lines
    MOSS_CLI_DETAIL        quiet | progress (default) | verbose
    MOSS_SHOW_THINKING     =true → print raw thinking deltas in verbose mode
    MOSS_TRACE             console → emit tracing spans to stderr
    MOSS_LLM_USAGE_LOG     path to append LLM usage JSONL records
    MOSS_LLM_USAGE         =1 → enable usage logging even without explicit path
    MOSS_SELF_LEARNING     =true → extract user correction feedback as memory

  Config file
    /Users/d-robotics/.config/dmoss/config.json
    .moss/config.json in the current workspace is read as project defaults

  Built-in features
    ✓ Session persistence (JSONL) with --resume-style recovery
    ✓ Long-term memory (memory_read / write / delete)
    ✓ Workspace context (USER.md, MEMORY.md, AGENTS.md auto-loaded)
    ✓ Skill learning — successful runs crystallize into SKILL.md
    ✓ Docker sandbox (MOSS_EXEC_BACKEND=docker)
    ✓ LAN Agent Mesh — P2P discovery via UDP broadcast
    ✓ Framework-level tool-call self-healing (stream-error resilient)
