## 与主流 Agent 的对比

### Moss 的独特优势
1. **机器人原生** - 其他 Agent 不支持机器人/嵌入式开发
2. **闭环自进化** - Teaching → Skill Learning 管线
3. **宿主中立** - 可嵌入任何产品
4. **零配置启动** - 内置网关

### 需要追赶的方面
1. **用户基数** - Claude Code/Cursor 有更多用户
2. **生态系统** - 更多插件和集成
3. **文档质量** - 需要更多教程和示例
4. **性能** - 需要优化速度和资源使用
